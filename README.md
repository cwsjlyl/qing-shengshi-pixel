# 最後的皇朝：康雍乾盛世（單一主畫面・高密度像素課堂教育遊戲）

本專案是專為香港小學六年級常識科設計的互動像素 RPG 課堂教育遊戲，主題為「最後的皇朝：康雍乾盛世」。採用純前端 **Vite + TypeScript + Phaser 3** 架構開發，無需任何後端伺服器、資料庫或外部 API 密鑰，可直接部署至免費 GitHub Pages 或嵌入學校教學網頁（如 Google Sites）。

---

## 遊戲特色與課堂設計

- **全螢幕單一主畫面佈局**：
  - 整個視窗只有一個統一的 Phaser 像素主畫面（標題、課堂分關、開場、三朝探索地圖及四個小遊戲均於同一主畫面呈現，自動適應 iPad 直向、橫向、手機與電腦螢幕，整數倍清晰縮放無模糊）。
  - **左下角**：圓形虛擬搖桿（支援 iPad／手機拇指多點觸控拖曳；電腦同時支援 WASD／方向鍵）。
  - **右下角**：「調查／傾談」互動大鍵（靠近人物、線索、挑戰桌或出口時自動高亮提示；電腦亦可用空白鍵或 Enter）。
  - **右上角**：「設定」按鍵（可開啟簡單選單：繼續遊戲、操作說明、返回標題畫面，課堂分關模式下亦可返回選關；不含任何付費或帳號功能）。
  - **疊加式半透明／卡牌面板**：對話、三題選擇題、密碼鍵盤、開場文字與離線問答全部疊加於主畫面上，開啟期間自動暫停主角移動，絕不遮擋探索視線。
- **高密度原創中式像素美術**：
  - 程式即時生成 64 款 24×24 高細節原創清代宮廷、江南與邊疆像素瓷磚（青磚微差與磚縫、漢白玉丹陛雲紋石雕、須彌座台基、雕花檻窗、鎏金門釘朱門、黃琉璃瓦重檐斗拱、太湖石、古松垂柳、三幀動態碧水荷池、建築與樹木投影層）。
  - 11 款 24×36 四向四幀流暢行走角色精靈（具眼白、瞳孔、眉型、清代冠帽紅纓頂珠、朝服補子衣摺、髮辮及貼地陰影）與 120×72 雕龍樓船御船。
- **兩種課堂進關入口與完整教學流程**：
  1. **由康熙順序探索**：依康熙 → 雍正 → 乾隆順序完成證據收集、小遊戲、三條選擇題及各關密碼過關。
  2. **課堂分關**：方便分組教學直接進入指定朝代，完成康熙或雍正關後返回課堂分關以備教導組員；乾隆關同樣支援完整結局與離線問答流程。

## 本地安裝與執行步驟

請確保電腦已安裝 Node.js（建議 v18 或以上版本），然後在專案資料夾執行以下指令：

```bash
# 1. 安裝開源依賴套件（phaser、vite、typescript）
npm install

# 2. 啟動本地開發伺服器
npm run dev

# 3. 進行 TypeScript 型別檢查並打包生產版本至 dist/ 資料夾
npm run build

# 4. 本地預覽打包後的靜態網站
npm run preview
```

## 部署至免費 GitHub Pages

`vite.config.ts` 已設定 `base: './'`，`index.html` 亦採用相對路徑 `./src/main.ts`，因此打包後的靜態檔可以放在 GitHub 專案站台的子路徑，也可以嵌入 Google Sites。

本倉庫的 GitHub Actions workflow 會在推送到 `main` 時執行 `npm ci` 與 `npm run build`，再用官方 Pages actions 發佈 `dist/`。這使用 GitHub 免費的 GitHub Pages 與 GitHub Actions，不使用付費方案或付費自訂網域。針對 `main` 的 pull request 只會驗證建置，不會部署。

部署成功之後，免費專案站台的網址是：

https://cwsjlyl.github.io/qing-shengshi-pixel/

在 `main` 上的 workflow 成功完成之前，這個網址尚未提供可玩的遊戲。
